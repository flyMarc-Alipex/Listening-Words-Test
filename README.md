# WordCard — 悬浮单词卡

一个悬浮在屏幕角落的英文单词助记小工具。基于 tkinter,完全离线,支持 macOS / Windows / Linux。

## 启动

- macOS:直接双击 `start.command`(首次运行如果被系统拦截,右键 → 打开)。
- 任意系统:在终端执行 `python3 word_card.py`。

> 需要自带 Tk 的 Python。macOS 推荐安装 [python.org](https://www.python.org/downloads/) 的 Python 3.11 以上版本;系统自带 Python 可能没有 tkinter(检查:`python3 -c "import tkinter"`)。

## 目录结构

```
WordCard/
├── word_card.py        主程序
├── start.command       macOS 双击启动脚本
├── README.md           本文件
├── 词表生成规则.md      词表格式与生成规范
├── wordlists/          词表文件(words.txt、day1-words.txt …)
└── data/               自动生成的学习数据
    ├── learned*.txt    各词表的已会记录
    ├── stats*.txt      各词表的对/错统计
    └── last_list.txt   上次选用的词表
```

## 词表

`wordlists/` 目录下每个 `.txt` 词表文件都是一份独立的词表。程序启动时会自动扫描该目录,通过右键菜单 →「词表」即可切换,并会记住你最后一次选用的词表,下次打开自动切回。每个词表有自己的已会记录互不影响。新词表文件直接放入 `wordlists/` 目录即可被识别。

词表格式,每行一条:

```
英文单词 <Tab 或 | 或 两个空格> 释义
```

以 `#` 开头的是注释行。释义留空的词也会出现在卡片上,翻面时显示「原文无提示」;想要跳过留空的词,把它们的空格行删掉即可。示例词可直接替换为你自己的词表。

## 操作

- 点击卡片或按空格:翻面显示释义(再按一次翻回)
- ← / →:上一个 / 下一个
- R:随机抽词
- S 或点击「已会」:为该词记 1 次正确(状态栏会显示该词的对/错次数);当某词满足「正确次数 - 错误次数 ≥ 3」时自动判为已学会,之后不再出现
- 点击「不会」:为该词记 1 次错误
- 点击卡片或按空格:翻面显示释义(再按一次翻回);听写模式下无翻面
- ← / →:上一个 / 下一个(听写模式下也会切换并播放新词音频)
- R:随机抽词;S 或点击「已会」:记 1 次正确
- 底部滑块:切换「读写 / 听写」模式
- 右键卡片:置顶开关 / 透明度调节 / 切换词表 / 简单统计 / 详细词表统计 / 打开当前词表 / 重置已会记录 / 退出

## 听写模式

把底部滑块拉到「听写」即进入听写模式:

- 每次切到单词(下一个/上一个/随机/提交后)都会用系统语音(macOS `say`)播放该词读音,播放完毕后才开始 5 秒倒计时。
- 输入框自动获得焦点,拼写后**按回车或点「提交」**:拼写正确记 1 次正确,拼错记 1 次错误,计数与读写模式完全一致(正确-错误 ≥ 3 自动判为已学会)。
- 5 秒倒计时结束会按当前输入强制提交:**写对了仍记正确**,没写对才记 1 次错误,然后自动进入下一个词;「重复」按钮可重播读音并重新计时。
- 提交后右侧会弹出释义小窗,显示该词和中文意思。**无论拼对还是拼错**,主窗口都停在当前词、释义窗保持显示,直到按回车/点「提交」才进入下一个词。
- 「暂停」按一下冻结倒计时(再按「继续」从剩余时间接着走,暂停期间超时不判错);「退出」立即退出听写模式回到读写。
- 对比拼写忽略大小写,只与单词本身比对。

## 统计

右键菜单里有两个统计入口,都会弹出独立窗口,左上角可切换查看任意词表:

- **简单统计**:列出当前词表错误次数最高的 30 个单词(按错误次数降序)。
- **详细词表统计**:列出词表里每个单词的正确次数、错误次数、正确率、错误率和学习状态(已学会 / 学习中)。选中某行可「标记为已学会」(该词正确次数置 3、错误次数置 0)或「移除已学会」(正确/错误次数均归 0),改动会同步反映到主卡片。

## 已会记录

标记已会的词写入 `data/` 目录下的记录文件(`words.txt` 对应 `data/learned.txt`,其余词表对应 `data/learned-<词表名>.txt`),下次启动自动跳过。每个词的正确/错误次数记录在 `data/stats.txt` / `data/stats-<词表名>.txt`,恢复复习请在「详细词表统计」里把想重背的词「移除已学会」,或在右键菜单点「重置已会记录」(只清空已会标记,不清空统计次数)。
